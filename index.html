Mode d'emploi

1. Le projet

Un projet = un site. Donnez-lui le nom du client (« PALM Mortagne »).

1 bis. Les types d'objets

Dans les Réglages, définissez ce que vous allez poser : boîtes de dérivation, BAES, canalis, points Q18… Chaque type a sa forme, sa couleur, sa dimension réelle en centimètres et son préfixe de numérotation (BD- donne BD-001, BD-002…). Sur un plan calé, un objet est dessiné à sa taille réelle : il grossit avec le zoom, et en dézoomant le plan reste lisible.

2. Le fond de plan

Importez le plan depuis le téléphone (PNG, JPG ou SVG). Un doigt pour déplacer, deux doigts pour zoomer.

3. Le calage (facultatif)

Il sert uniquement à afficher votre position et à pré-positionner les repères. Deux méthodes, au choix :

① Saisir les coordonnées — la plus juste. Sur l'ordinateur, clic droit dans Google Earth sur deux points reconnaissables du site : il donne leurs coordonnées, vous les recopiez. Rien à mesurer sur place.

② Mesurer au GPS — vous vous placez dehors sur chaque point. Attention : il faut vraiment marcher entre les deux mesures, sinon le téléphone renvoie deux fois la même position et le calage est faux.

Dans les deux cas, l'appli annonce la taille qu'aurait votre plan. Si ce n'est pas la bonne, n'enregistrez pas.

4. Poser un objet

Bouton +. Le repère apparaît sur votre position GPS si elle est connue, sinon au centre de l'écran. Faites-le glisser au bon endroit, validez, remplissez la fiche : statut, photos, note.

6. Exporter

Rien à enregistrer : tout est écrit dans le téléphone au fur et à mesure. Le bouton Exporter le relevé sert seulement à sortir un fichier ZIP unique — le listing, les photos, le plan et de quoi regénérer le DXF. Le soir, on l'envoie dans Dropbox.

7. En plein soleil

Le bouton ☀ en haut à droite du plan passe le fond en blanc : le plan redevient lisible dehors.

Aucune donnée ne sort du téléphone. Pensez à exporter une sauvegarde JSON à la fin de chaque journée.

Envoyer vers…

Ouvre le menu de partage du téléphone. Dropbox se trouve dans la liste du bas (« Enregistrer dans Dropbox »), pas dans la rangée d'icônes du haut — il faut faire défiler. Si Dropbox n'y est pas du tout, c'est que l'application n'est pas installée sur ce téléphone.

Enregistrer dans Fichiers

Dépose le fichier dans l'application Fichiers de l'iPhone. De là, Dropbox apparaît comme un dossier : vous pouvez l'y glisser. C'est le chemin de secours quand le menu de partage ne propose pas ce qu'il faut.

Dropbox absent du menu de partage ?

L'application peut être installée sans que son extension soit activée. Dans le menu Envoyer vers…, descendez tout en bas de la liste : Modifier les actions… → allumez Dropbox. La poignée à droite permet de le remonter en tête pour les prochaines fois.
